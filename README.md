# Platform Forge

A local-first platform engineering learning environment. Learn by investigating failures, writing code, checking results and explaining tradeoffs.

This project is under active development. The browser edition and optional Docker/AI services have deliberately different capabilities; see the capability matrix and setup instructions as they are added.
